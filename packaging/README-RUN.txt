TechReader - how to run
=======================

1. Keep screenreader.exe and the _internal folder together
   (this whole folder must stay as it is).

2. Double-click screenreader.exe.
   You will hear the start sound and speech announcements begin.
   A log file is written to %APPDATA%\TechReader\screenreader.log;
   that is normal and the program folder stays clean.

3. Keys:
   Ctrl                - stop the current speech
   CapsLock + Space    - open / close the TechReader menu
                         (arrows to move, Enter to choose, Escape to close)

4. Settings: menu -> Preferences -> Settings...
   (Speech, Output, Event announcements, Keyboard categories)

5. To close TechReader completely: menu -> Exit.

Troubleshooting
---------------
- No speech? Check the volume mixer, and that another screen reader
  is not talking at the same time.
- If anything goes wrong, send %APPDATA%\TechReader\screenreader.log
  (press Win+R, type %APPDATA%\TechReader, press Enter to find it) back.
- First start can be a little slower while Windows settles.
